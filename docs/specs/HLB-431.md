# FashionFindrs Linear export and Plane import

Canonical specification: https://linear.app/fashionfindrs/issue/HLB-431

Use read-only, team-scoped, paginated exports with explicit archived and
association coverage. Preserve immutable identities, original payloads,
checksums and a coverage ledger. Raw private records and credentials never enter
Git; protected export storage and sanitized test evidence are separate.

HLB-442 starts the source issue export contract. HLB-443 expands association
traversal; later children own coverage/deltas, assets, dry-run, identity-safe
imports, resume, graph/content imports and independent reconciliation.

Linear stays authoritative. This integration branch authorizes no destination
data mutation or cutover. Runtime/import gates remain tracked independently.
